# osascript DXT
Control your Mac through osascript/AppleScript, with MCP, wrapped with DXT. Originally from [k6l3/osascript-dxt](https://github.com/k6l3/osascript-dxt)

## Overview

Follow developer instructions at https://github.com/anthropics/dxt to get setup with `dxt`. Run `dxt pack` to build `osascript.dxt`.
