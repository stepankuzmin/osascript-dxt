# macOS MCP

Control your Mac through osascript/AppleScript, with MCP Bundle. Originally from [k6l3/osascript-dxt](https://github.com/k6l3/osascript-dxt)

## Installation

Download the latest release from [Releases](https://github.com/stepankuzmin/macos-mcp/releases) and double-click the `macos.mcpb` file to install it.

## Contributing

Follow developer instructions at https://github.com/anthropics/mcpb to get setup with `mcpb`. Run `mcpb pack` to build `macos.mcpb`.
